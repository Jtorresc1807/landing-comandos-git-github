Crea un directorio
Ubicarse en el directorio
01

Inicializar Proyecto

$ mkdir proyecto-git
$ cd proyecto-git
$ git init
$ git clone /path/repositorio (local)
$ git clone username@host:/path/repositorio (remoto)
02

Primer commit local

$ git add nombre_archivo
$ git add .
$ git rm nombre_archivo
$ git commit -m "proyecto base"
03

Crear repo en Github (Web)

Crear un repositorio remoto en Github

04

Vincular con la nube (github)

$ git remote add origin URL_DEL_REPO_REMOTO
05

El gran push

$ git push origin master
06

Actualización (Nuevos cambios)

$ git status
$ git add .
$ git commit -m "nuevo cambio"
$ git push origin master
