Practica Git y GitHub

Comandos Basicos Git y GitHub


01

Inicializar Proyecto

Crear un directorio
$ mkdir proyecto-git
Ir al directorio
$ cd proyecto-git
Crea un nuevo repositorio
$ git init
Clonar un repositorio local
$ git clone /path/repositorio
Clonar un repositorio remoto
$ git clone username@host:/path/repositorio
02

Primer commit local

Envia un archivo al (stagin area)
$ git add nombre_archivo
Envia todos los archivos al (stagin area)
$ git add .
Elimina del staging area y directorio
$ git rm nombre_archivo
Guardado oficial Snapshot y comentario
$ git commit -m "proyecto base"
03

Crear repo en Github (Web)

Crear un repositorio remoto en Github

04

Vincular con la nube (github)

Relaciona el repositorio local con el repo remoto
$ git remote add origin URL_DEL_REPO_REMOTO
05

El gran push

Sube los cambios a la rama master del repo remoto
$ git push origin master
06

Actualización (Nuevos cambios)

Muestra las modificaciones antes de commit o git add
$ git status
Envia todos los archivos al (stagin area)
$ git add .
Guardado oficial Snapshot y comentario
$ git commit -m "Desc nuevo cambio"
Sube los cambios a la rama master del repo remoto
$ git push origin master
07

Manejo de Ramas

Lista las ramas que existen
$ git branch
Crea una rama
$ git branch nombre_de_la_rama
Pasarse a otra rama
$ git switch nombre_de_la_rama
Fusiona cambios que ya están en tu repositorio local.
(combina dos ramas locales)
$ git merge nombre_de_la_rama
(git fetch & git merge) descarga los ultimos cambios del
servidor remoto y fusiona automáticamente con la rama local
$ git pull origin nombre_de_la_rama
08

Otros Comandos

Mostrar el historial de confirmaciones (commits) cronologicamente
$ git log
Cambia tu directorio al estado de la confirmación (commit)
histórica
$ git checkout nombre_archivo
